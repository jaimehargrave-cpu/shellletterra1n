# shellletterra1n

A terminal-based letter rain animation in Python, inspired by the classic falling-character screens.

## Run

```bash
python3 main.py
```

## Controls

- `q` or `Esc` to quit
- `s` to toggle slow mode
- `r` to reset

## Notes

This project uses Python's built-in `curses` module, so it runs best in a terminal that supports ANSI escape sequences and standard TTY behavior.
